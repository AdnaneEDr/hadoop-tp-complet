1. OU PLACER CE DOSSIER ?
-------------------------
 - Docker (option B du TP-0) : decompressez l'archive DANS le dossier
   hadoop-docker/, a cote de docker-compose.yml. Le dossier
   hadoop-docker/donnees est alors visible dans le cluster sous /opt/donnees.
 - Windows natif (option A) : decompressez dans C:\donnees et remplacez
   /opt/donnees par C:\donnees dans les commandes du livret.

4. CHARGEMENT RAPIDE DANS HDFS (rattrapage)
-------------------------------------------
 Le livret fait charger les fichiers pas a pas. Pour tout recharger d'un coup :
   Docker  : docker compose exec namenode bash /opt/donnees/charger_hdfs.sh
   Windows : double-clic sur charger_hdfs.cmd (cluster demarre)
 Verifier que les fichiers ne sont pas abimes : bash verifier.sh
